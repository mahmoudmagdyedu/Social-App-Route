# Social · حكايات تقرّبنا

تطبيق تواصل اجتماعي عربي كامل مبني بـ React + TypeScript + Vite. ألوانه من مرجع Route Posts: خلفية رمادي فاتح، كروت بيضاء، وأزرق غامق `#00298d`، مع هوية وتفاصيل خاصة بالتطبيق.

## تشغيل المشروع

```bash
npm ci
npm run dev
```

افتح الرابط اللي Vite بيطبعه. الـ API الافتراضي هو `https://route-posts.routemisr.com`، ومش محتاج API key. اعمل حساب من صفحة التسجيل أو استخدم حساب Route Posts موجود.

لو محتاج تغيّر الخادم، انسخ `.env.example` إلى `.env.local` وعدّل `VITE_API_URL`، وبعدها أعد تشغيل Vite. ما تحطش أسرار في متغيرات `VITE_`؛ قيمها بتوصل للمتصفح.

```bash
npm run build
npm run preview
npm run lint
npm test
```

`npm test` بيختبر طبقة الخدمات والأخطاء باستخدام mocks، من غير ما يغيّر بيانات الخادم. `npm run verify:api` اختبار تكامل حقيقي: بيستخدم أو ينشئ حسابين QA، ويجرب العمليات بينهم، وينظف المنشورات المؤقتة. بيانات QA بتتحفظ في ملفات `*.local.json` المتجاهلة في Git. الـ API مفيهوش حذف حساب، فالحسابات التجريبية نفسها بتفضل موجودة. التقرير بيتحفظ في `docs/api-verification.json`.

## الوظائف

- تسجيل حساب ودخول بالبريد أو اسم المستخدم، حفظ الجلسة، حماية المسارات، خروج ومعالجة انتهاء التوكن.
- منشورات عامة وFeed للمتابَعين، فلتر الصور، صفحات نتائج، وصفحة تفاصيل لكل منشور.
- إنشاء وتعديل وحذف منشوراتك، رفع الصور ومعاينتها، الإعجاب، قائمة المعجبين، الحفظ والمشاركة.
- تعليقات وردود بالنص والصورة، تعديل وحذف، وإعجاب بالتعليقات والردود.
- الملف الشخصي، منشورات المستخدم، متابعة وإلغاء متابعة، واقتراحات ناس جديدة.
- إشعارات الكل وغير المقروءة، عداد متجدد، تحديد واحدة أو الكل كمقروء، وروابط للتفاعل.
- تغيير الصورة الشخصية وكلمة السر، مع استخدام التوكن الجديد اللي بيرجعه الخادم.
- واجهة عربية RTL للموبايل والكمبيوتر، Skeleton، Empty State، Error State، ورسائل نجاح وخطأ.

البحث في «اكتشف» بيصفّي الاقتراحات المعروضة في الصفحة الحالية. التوثيق المرفق مفيهوش endpoint للبحث العام أو استعادة كلمة السر أو تعديل الاسم أو رفع الغلاف؛ التطبيق ما بيعرضش أزرار توحي بعمليات غير موجودة. الإشارات بتتكتب بصيغة `@username` والخادم بيتولى معالجتها.

## الشرح وهيكلة الكود

اقرأ [الشرح الهندسي العربي](docs/شرح-المشروع.md) بالترتيب من الأسبوع الأول للخامس، وبعده [خريطة الـ API](docs/api-map.md).

```text
src/
├── App.tsx                 # Router وحماية المسارات
├── Layout/                 # التخطيط المشترك وOutlet
├── Nav/                    # الشريط العلوي
├── pages/                  # الدخول، Feed، الملف، التفاصيل، الاكتشاف، الإشعارات، الإعدادات
├── components/             # بطاقات المنشورات، التعليقات، النماذج، الأيقونات، النوافذ
├── context/                # AuthContext وAuthProvider
├── hooks/                  # useCollection وuseResource
├── services/               # fetch، الـ endpoints، validation، formatting
└── types/                  # شكل بيانات الخادم
```

المكونات Arrow Functions بـ default export، JSX واضح، Props وتحديثات State باستخدام spread وfunctional updater، وطلبات `fetch` مستقلة عن مكونات العرض؛ قريب من أسلوب المشروع المرفق مع الحفاظ على TypeScript الموجود بالفعل في Social-App.

## النشر

ارفع محتوى `dist` على استضافة Static بتدعم إعادة توجيه المسارات إلى `index.html`، لأن التطبيق بيستخدم BrowserRouter. ملفات الخط Tajawal محلية داخل `public/fonts` ومعاها رخصة OFL. مفيش backend محلي؛ البيانات والصور الفعلية محفوظة عند خدمة Route Posts.
