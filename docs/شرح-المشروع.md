# شرح المشروع

## البداية

`src/main.tsx` يشغّل React ويحمّل التنسيق من `src/index.css`. ملف `src/App.tsx` يحدد المسارات ويربط كل مسار بالصفحة الخاصة به. المكونات والدوال مكتوبة بصيغة `function`، والمكتبات هي الموجودة بالفعل في المشروع.

## طلبات API

كل الطلبات مكتوبة في `src/API/API.ts`. كل عملية لها دالة باسم واضح بدل تجميع العمليات في كائنات خدمات:

```tsx
import { getPosts, createPost } from '../API/API';

let result = await getPosts(1);
let posts = result.items;

await createPost('أول منشور');
```

دالة `request` داخل الملف تنفّذ `fetch` وترسل التوكن وتقرأ الرد وتعالج الخطأ. دوال المنشورات والتعليقات والمستخدمين والإشعارات تستخدمها حتى يكون إرسال التوكن ومعالجة الرد في مكان واحد.

رابط الخادم مكتوب في `API_URL` داخل نفس الملف. الطلبات التي فيها صورة تستخدم `FormData`، والطلبات العادية تستخدم `JSON.stringify`.

## التوكن والدخول

`src/context/AuthProvider.tsx` يحفظ التوكن بعد نجاح الدخول:

```tsx
localStorage.setItem(TOKEN_KEY, data.token);
```

كل طلب محمي يقرأ التوكن من `localStorage` ويضعه في `Authorization: Bearer`. عند إعادة فتح التطبيق، يتم جلب المستخدم من الخادم بالتوكن المحفوظ. الخروج يمسح التوكن ويعيد المستخدم لصفحة الدخول. المفتاح هو `social-app-token` حتى تستمر الجلسات الموجودة.

## الصفحات والمكونات

- `Home/Home.tsx`: عرض المنشورات والمحفوظات والفلاتر.
- `Auth/Auth.tsx`: نموذج الدخول أو التسجيل حسب المسار.
- `Profile/Profile.tsx`: بيانات المستخدم والمنشورات والمتابعة.
- `PostDetails/PostDetails.tsx`: المنشور وتعليقاته.
- `Discover/Discover.tsx`: اقتراحات المستخدمين.
- `Notifications/Notifications.tsx`: الإشعارات وتحديدها كمقروءة.
- `Settings/Settings.tsx`: الصورة الشخصية وكلمة السر.
- `Layout/Layout.tsx` و`Nav/Nav.tsx`: التخطيط والتنقل.

المكونات المشتركة داخل `src/components`، مثل بطاقة المنشور والتعليقات ورفع الصور. البيانات المتغيرة محفوظة في `useState`، والأحداث تنادي دوال API وتحدث الحالة بعد الرد.

## تحميل البيانات

`useCollection` يحمّل قائمة مع رقم الصفحة، و`useResource` يحمّل عنصرًا واحدًا. الاثنان داخل `src/hooks` لمنع تكرار التحميل ومعالجة الخطأ في كل صفحة. إلغاء الطلب عند تغيير الصفحة يمنع الرد القديم من استبدال البيانات الجديدة.

## النماذج

التحقق داخل `src/services/validation.ts` باستخدام Zod الموجودة بالفعل. رسالة الخطأ تظهر بجانب الحقل، وطلب الدخول أو التسجيل يتنفذ بعد نجاح التحقق. رفع الصور يتحقق من النوع والحجم قبل الطلب.

## التشغيل والفحص

شغّل `npm ci` ثم `npm run dev`. استخدم `npm run build` لفحص TypeScript وتجهيز التطبيق، و`npm run lint` لفحص الكود. بعد التشغيل جرّب الدخول والخروج، إضافة منشور، التعليقات، والمحفوظات بحسابك العادي.
